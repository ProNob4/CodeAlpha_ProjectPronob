# CodeAlpha Data Science Internship Projects

This repository contains my completed tasks for the **CodeAlpha Data Science Internship**.

## 📌 Tasks Overview

### Task 1: Iris Flower Classification
- **Objective:** Classify Iris flower species (*setosa*, *versicolor*, *virginica*) based on physical sepal and petal measurements.
- **Tech Stack:** Python, Scikit-learn, Pandas, Seaborn, Matplotlib.
- **Model:** Random Forest Classifier.
- **Notebook:** `Task1_Iris_Classification.ipynb`

### Task 2: Unemployment Analysis with Python
- **Objective:** Analyze unemployment rate trends with a specific focus on the socioeconomic impact and spike during the COVID-19 pandemic.
- **Tech Stack:** Python, Pandas, Matplotlib, Seaborn.
- **Notebook:** `Task2_Unemployment_Analysis.ipynb`

### Task 4: Sales Prediction using Python
- **Objective:** Predict sales figures based on advertising expenditure across TV, Radio, and Newspaper channels.
- **Tech Stack:** Python, Scikit-learn, Linear Regression, Random Forest Regressor.
- **Notebook:** `Task4_Sales_Prediction.ipynb`

---

## 🚀 How to Run
1. Open any of the `.ipynb` files directly in Google Colab or Jupyter Notebook.
2. Run all cells sequentially to reproduce data cleaning, visualizations, and model evaluations.
